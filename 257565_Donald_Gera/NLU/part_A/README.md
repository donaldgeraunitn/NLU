
## Dependencies

Install the dependencies from the submission-level `requirements.txt` file. 

## Evaluate the submitted best model

The submitted checkpoint is expected at:

```text
bin/best_model.pt
```

Evaluate it on the ATIS test split with:

```bash
python main.py --eval --checkpoint bin/best_model.pt
```

The script rebuilds the dataset mappings and verifies that they match the mappings stored in the checkpoint before evaluating the model. It then prints test loss, slot F1, and intent accuracy.

A different dataset directory can be supplied when needed:

```bash
python main.py --eval --checkpoint bin/best_model.pt --dataset_dir dataset/ATIS
```

## Reproduce the predefined experimental procedure

The experiments are executed sequentially because later stages reuse the reports generated by earlier stages.

### 1. Baseline learning-rate search

```bash
python main.py --experiment baseline_lr
```

### 2. Greedy architectural tuning

This stage tunes `d_model`, `n_heads`, `num_layers`, and `ff_dim` one at a time, preserving the winner from each step.

```bash
python main.py --experiment greedy_hparams
```

### 3. Final learning-rate readjustment

```bash
python main.py --experiment final_lr
```

### 4. Dropout tuning

```bash
python main.py --experiment dropout
```

### 5. Final repeated runs

This stage repeats the best available configuration. Set `--runs_per_config` to the required number of runs.

```bash
python main.py --experiment final_runs --runs_per_config 5
```

The selected checkpoint produced by a stage is saved as `best_model.pt` in that stage's output directory. Copy the final submitted checkpoint to:

```text
bin/best_model.pt
```

## Train a custom configuration

Use `--experiment custom` together with an explicit learning rate. Any architecture argument that is not provided keeps its baseline default value.

```bash
python main.py --experiment custom \
  --learning_rate 0.005 \
  --d_model 80 \
  --n_heads 2 \
  --num_layers 4 \
  --ff_dim 20 \
  --dropout 0.1
```

## Main CLI arguments

| Argument | Purpose |
|---|---|
| `--experiment` | Select `baseline_lr`, `greedy_hparams`, `final_lr`, `dropout`, `final_runs`, or `custom`. |
| `--eval` | Skip training and evaluate a saved checkpoint. |
| `--checkpoint` | Path to the checkpoint used with `--eval`. |
| `--dataset_dir` | ATIS dataset directory. Default: `dataset/ATIS`. |
| `--output_dir` | Override the default output directory for the selected experiment. |
| `--selection_metric` | Select `slot_f1`, `intent_acc`, or `average`. Default: `slot_f1`. |
| `--runs_per_config` | Number of repeated runs for each candidate configuration. |
| `--seed` | Model initialization and training-shuffle seed. |
| `--data_seed` | Fixed seed used to build the train/development split. |
| `--eval_every` | Number of epochs between development-set evaluations. |
| `--learning_rate` | Force one learning rate where supported. |
| `--learning_rates` | Candidate values used during learning-rate searches. |

The remaining CLI options expose batch sizes, patience, number of epochs, weight decay, device selection, candidate architecture values, custom architecture values, and report paths.
